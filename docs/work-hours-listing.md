## Technologies used in the project

- **Languages:** Go, TypeScript, JavaScript, SQL, HTML, and CSS.
- **Frontend:** React, React Router, Vite, Axios, TanStack Query, Zustand, Radix UI, Heroicons, and react-easy-crop.
- **Backend and security:** Go's `net/http` and `log/slog`, HttpOnly cookie sessions, Argon2id password hashing, and zxcvbn password validation.
- **Database:** PostgreSQL, Neon, pgx, sqlc, and Goose migrations.
- **Object storage:** S3-compatible storage with RustFS for local development, Neon storage, and AWS SDKs.
- **Scheduled tasks:** Neon Functions and Hono for session and storage cleanup.
- **Development and checks:** pnpm, Node.js, Biome, Air, just, and Go formatting, vetting, and tests.
- **Deployment:** Docker, Docker Compose, Nginx, GitHub Actions, and Render.

Earlier tools replaced during development: Tailwind CSS, MinIO, JWT authentication, pg_cron, and ESLint.
